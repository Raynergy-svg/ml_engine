# Vercel Open Source bounty notes

Source: https://ooosec.com/programs/vercel-open-source
Checked: 2026-05-17

Relevant scope:
- Tier 1 includes vercel/next.js, vercel/ai, vercel/ms, vercel/workflow, vercel-labs/skills, turborepo, etc.
- Focus areas include compiler security/code injection, build system integrity, data fetching/caching, AI integration security.
- Must test open source projects in local/dev environments, not production Vercel services or CI.
- Reports require reproducible PoC code/artifact.
- Rewards: medium average around $1,240, high average around $5,909.

Submission bar:
- Discard dependency-only issues.
- Discard templates/docs/examples.
- Prefer default configuration or typical deployment impact.
