# Claude Code Agent Personalities

This directory contains 37 LLM personality prompts from the [agency-agents](https://github.com/msitarzewski/agency-agents) repo. These are **reference material** for Claude Code sessions — specialized AI roles for engineering, testing, and strategy tasks.

These are NOT the 12 scanner agents in `src/scanner/agents.py`. The scanner agents are code-level evaluators that run during market scans. These files are prompt templates that can be activated during development sessions.

## Categories
- `engineering-*` — Software engineering roles (AI engineer, backend architect, etc.)
- `testing-*` — QA and testing roles (API tester, performance benchmarker, etc.)
- `strategy-*` — Business strategy roles
- `agents-orchestrator.md` — Multi-agent workflow coordinator
- `specialized-*` — Domain-specific specialists
