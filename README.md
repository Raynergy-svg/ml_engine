# ML Engine
A simple machine learning tool for stock market predictions and algorithm trading.

## Getting Started
- **Clone and Setup**: `git clone https://github.com/Raynergy-svg/ml_engine.git && cd ml_engine`
- **Set Environment**: `python -m venv venv && source venv/bin/activate`
- **Install Packages**: `pip install -r requirements.txt`

## Key Features
- Train and predict using one command.
- Real-time performance dashboard.
