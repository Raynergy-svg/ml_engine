FEATURES
========

✅ Automatic model switching based on rolling accuracy
✅ Per-pair optimization (each pair gets best model)
✅ Exponential moving average (EMA) for accuracy tracking
✅ Thread-safe file persistence with fcntl locking
✅ Graceful error handling (never crashes scanner)
✅ Comprehensive audit trail (JSONL append-only log)
✅ Simple integration (minimal changes to existing code)
✅ Configuration options (thresholds, windows, etc.)
✅ Status monitoring and debugging tools
✅ Full test coverage (30+ tests)

KEY PARAMETERS
==============

rolling_window:     30 trades (EMA window)
min_trades:         30 (min evaluations before switch)
switch_threshold:   0.02 (2% improvement to switch)

Customizable: Yes (see docs for examples)

===========

  src/scanner/automation/continuous.py, Step 5h

  PairModelSelector().check_switch(pair)

USAGE
=====

Basic usage:
  from src.scanner.automation import PairModelSelector
  
  selector = PairModelSelector()
  selector.record_prediction("EUR_USD", "joint", "LONG", "LONG")
  
  new_model = selector.check_switch("EUR_USD")
  if new_model:
      selector.execute_switch("EUR_USD", new_model)

Integration in continuous.py:
  pms = PairModelSelector()
  for pair in traded_pairs:
      new_model = pms.check_switch(pair)
      if new_model:
          pms.execute_switch(pair, new_model)

See docs for detailed examples and patterns.
