5. BEHAVIORAL CHANGES
================================================================================

PRE-EXECUTION FLOW (Updated):
1. Fetch OHLCV data
2. Check incremental cache
3. Compute features
4. Run inference
5. Apply specialist agents
6. ← [NEW] BACKTEST GATE APPLIED HERE ←
   - Validate signal on recent candles
   - Calculate win rate
   - Apply soft confidence penalty if needed
7. Cache result
8. Return PairAnalysis

CONFIDENCE ADJUSTMENT:
- PASS (win_rate >= 55%): +0.0 (no change)
- FAIL (win_rate < 55%): -0.15 (soft penalty)
- No Data: +0.0 (no block, don't penalize)
- Error: +0.0 (graceful degradation)

POSITION SIZING IMPACT:
- Original confidence: 0.65
- After backtest fail: 0.50
- Position size: 0.50 / 0.65 = 77% of original
- Risk naturally scales down
